# Privacy Policy and ToS live on GitHub Pages, same URL in-app and on the store

Store review requires a public Privacy Policy URL. In-app-only markdown fails
review; a Notion/Doc URL can rot and is not in the repo. v1.1 hosts
`docs/legal/` on GitHub Pages at
`https://callmerev95.github.io/Cashtrix/` (privacy + terms), and the in-app
screens open that URL. Store listings use the same URL.

v1.1 copy is **English only**. Bilingual ID+EN is two legal texts that must
stay in sync; Indonesian lands with the v1.2 i18n pass (C6).

**Considered**: markdown bundled in the app only. Rejected — Apple/Play want a
fetchable URL. **Considered**: Notion. Rejected — not versioned with the repo.
**Considered**: ID+EN for v1.1. Rejected — drift risk; EN is enough to pass
review.
