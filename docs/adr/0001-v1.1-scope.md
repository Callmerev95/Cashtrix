# v1.1 is a store-ready slice, not the original §5.1 list

Original PRD §5.1 named v1.1 as transfer + recurring + offline outbox + biometric
+ CSV import. After the v1.0 code audit, the blockers to a real release were
unmeasured crash-free rate (observability still a ring buffer), no distribution
pipeline (`eas.json` missing), and store-review rejects (no password reset, no
privacy/ToS, email still auto-confirm). Scope was frozen 2026-09-19 as R6:
pre-release auth/legal, EAS + Sentry, transfer, recurring, full calendar, undo
delete, archive wallet. Outbox moved to v2.0 because it reverses the MVP rule
"writes are refused, not blindly queued". Biometric, CSV import, search, bulk
edit, i18n, 2FA moved to v1.2.

**Considered**: ship the original five features and worry about the store later.
Rejected — adding features does not make an unreleasable build releasable.

Catalogue: `docs/roadmap.md`. Binding revision: PRD §6.1 R6.
